# Technology Stack: webtrees.js

## Backend
- **Framework:** [NestJS](https://nestjs.com/) (version 11+)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **ORM:** [TypeORM](https://typeorm.io/)
- **Databases Supported:** MySQL, PostgreSQL, SQLite, SQL Server (via TypeORM)
- **Architecture:** Modular architecture with support for controllers, services, and repositories.

## Frontend
- **Framework:** [Next.js](https://nextjs.org/) (version 15+)
- **Library:** [React](https://react.dev/) (version 19+)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (version 4+)
- **UI Components:** [Radix UI](https://www.radix-ui.com/)
- **Data Fetching:** [TanStack Query](https://tanstack.com/query/latest) (version 5+)
- **State Management:** [React Hook Form](https://react-hook-form.com/) (for forms)
- **Validation:** [Zod](https://zod.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)

## Tooling & Infrastructure
- **Development Language:** TypeScript (across the entire stack)
- **Monorepo Structure:** Backend and frontend managed within a single repository.
- **Legacy Reference:** Original PHP source available for reference in the `webtrees/` directory.
